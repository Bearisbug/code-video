# fui-hud · 电影科幻界面（Cyberpunk HUD · FUI）

| 字段 | 值 |
|---|---|
| id | `fui-hud` |
| 渲染层 | HyperFrames · Three.js（主体与辉光）+ DOM/SVG（HUD 叠层）+ canvas 2D（波形、频谱） |
| 画幅 | 16:9 |
| 时长 | 默认 10 秒（300 帧 @30fps），可用 8–15 秒 |
| BPM | 120 |
| 适用用途 | 科技产品或 AI 功能发布 teaser、地点或答案的揭晓瞬间、数据大屏开机动画、游戏任务简报、发布会片头 |
| 状态 | 草稿，未盲测 |
| 证据 | 第三方风格合集视频（作者未确认）中「赛博朋克 HUD」一段的逐帧拆解（风格卡 + 独立核验，记录在作者未公开的工作区）；数值取自核验后的观察值，实现方式为推断；辉光参数与换色写法为本机 0.8.96 实测 |

## 风格语法

### 叙事骨架

单段不循环：开机 → 搜索 → 捕获 → 锁定 → 保持 → 关机。只有锁定一下是重拍，其余是「持续小动 + 分批出现」。

### 配色

搜索阶段全青。锁定时中心区先硬切琥珀，上半部面板晚 2–3 帧跟进；网格、迷你雷达、频谱、数据流保留暗青，形成青橙并存。

| hex | 角色 | 阶段 |
|---|---|---|
| `#010C0D` | 底色，近黑墨青 | 搜索 |
| `#04191F` | 面板暗层、蜂窝底纹、分隔线 | 全程 |
| `#1C7C86` | 次级刻度、经纬网 | 搜索 |
| `#3FC0C7` | 主线条 | 搜索 |
| `#45E8E5` | 高光 | 搜索 |
| `#DDEFF1` | 发光线条的近白核心、准星 | 搜索 |
| `#FBFEFE` | 大读数 | 搜索 |
| `#080302` | 底色，近黑暖褐 | 锁定后 |
| `#AC6833` | 弧环 | 锁定后 |
| `#F3BE5D` | 高光、角括号 | 锁定后 |
| `#FEE35E` | 锁定主标题 | 锁定后 |
| `#18818A` | 保留青色的网格与次级模块 | 锁定后 |

画面 73–95% 的像素亮度低于 20/255。没有面填充，只用 1px 细线、虚线刻度圈、罗盘数字、切角标签胶囊、四角 L 形括号和淡蜂窝底纹。

文字颜色：小字一律用高光色加 60% 不透明度（搜索阶段 `#45E8E5`，在纯底色上对比度 5.18；锁定后 `#F3BE5D`，4.68）；压在线框主体或亮线上的文字提到 80%（reg-002 实测 60% 时只有 3.97:1）。`#1C7C86`、`#AC6833` 只用于线条和刻度，不用于文字。blind-02 里暗青、暗琥珀小字实测只有 2.43:1 与 3.64:1，被 `check` 的对比度检查报错。

### 版式

- 中心：大圆仪表，3–4 层同心弧段各自以不同速度正反向慢转（如 +6°/s、−10°/s、+3°/s），加十字准星与横向刻度尺；圆内是线框主体，背面线条压暗。题材抽象时，主体选一个能画成线框的隐喻物：代码库画成文件楼群（楼高表示行数），网络画成节点图，数据画成柱阵地形。罗盘数字会被锁定标题压住时，把那几个数字去掉，弧环本身照转。
- 锁定条：锁定标题下方一条横贯中心仪表的细线，两端带斜纹端帽。
- 左右各一栏细框模块：自检日志、一个大号读数、遥测条、迷你雷达、波形、候选列表、频谱柱、十六进制数据流。
- 顶部居中一个切角状态胶囊，四角 L 形括号框住画面。
- 只有一个大读数和中心主体是亮的，其余都是低不透明度的小字。用户要求结尾出现产品名或标题时，它在收尾段成为第二个亮元素。

### 字体

| 元素 | 字体（见 `fonts.md`） | 1080p 字号 |
|---|---|---|
| 小标签：全大写、编号前缀 01–06，后接中文副标 | Share Tech Mono 400；中文副标 Noto Sans SC 400 | 12–14px，字距 0.15em，不透明度 60%（装饰性） |
| 大读数：固定位数补零，`font-variant-numeric: tabular-nums` | Rajdhani 700 | 48px |
| 锁定主标题：中文与同高英文大写词左右夹住准星 | Noto Sans SC 900 + Rajdhani 700 | 中文 84px；英文 = 中文 × 1.5 ≈ 127px（汉字墨迹约 0.97 em，Rajdhani 700 大写字高 0.643 em，字号相同时英文只有中文的三分之二高） |
| 结尾产品名（用户要求出现时） | Rajdhani 700，近白 `#FBFEFE`，乱码解码出现 | 96px，底部居中，安全区内；落定帧配一个 `impact`（`gain` 0.3） |
| 坐标行、日志 | JetBrains Mono 400，带块光标 | 16px（装饰性） |

### 运动

| 项 | 数值 |
|---|---|
| 分批出现 | 打字、逐条点亮、弧段旋入，批次间隔 0.1–0.3 秒 |
| 常驻次级运动 | 弧环恒速转、主体 8°/s 恒速自转、波形横向滚动、频谱跳动、数据流翻页、读数缓慢递减 |
| 文字出现 | 乱码解码：先每帧换一组随机字符约 0.25 秒，再落定（随机种子取帧号，`DET-001`） |
| 读数收敛 | 指数缓出，约 1.3 秒收敛到终值（`DET-004`） |
| 锁定蓄力 | 四个大 L 括号带残影从圆外飞入，约 0.35 秒收拢成目标框，框角显示递增的百分比与 T- 倒计时，同时主体变暗 |
| 锁定冲击 | 闪白 1 帧 → 中心硬切琥珀（不做渐变）→ 整幅舞台 ease-out 推近到 1.12 倍，中心圆环放大到 1.2–1.5 倍并加放射残影，持续约 0.5–0.6 秒（取落在整帧与半拍网格上的值）→ 1 帧弹回原尺寸，弹回帧带横向重影 |
| 锁定后 | 锁定条两端斜纹端帽闪三下，间隔 0.5 秒，每次 1 帧起、约 0.1 秒衰减；之后约 1.3 秒静态保持 |
| 开关机 | CRT 开机：亮横线在 3 帧内上下裂开成整屏；CRT 关机：纵向压成亮线再缩成点，各约 0.3 秒 |

### 镜头

正面锁定的 2D 构图，没有手持晃动和环绕运镜。全片只在锁定时推近一次；主体自身可以旋转。

### 声音

`synth.py` 的 `pulse` 音床，120 BPM，小调和弦（如 `"A2 E3 A3"`、`"F2 C3 F3"`）。开机 `impact`（`gain` 0.35）；日志每行一个 `tick`；捕获时 `glitch` 加 `blip`；逼近阶段每 0.5 秒一个 `blip`；锁定前 0.1 秒的空拍写进 `bed.automation`（`AUD-003`），锁定帧落全片最响的 `impact`（`gain` 1.0）叠 `alarm`（`gain` 0.7）；三次端帽闪烁各配一个 `alarm`。开机 `impact` 的 `gain` 超过 0.5 时会比锁定还响（blind-02 实测）；关机时音床淡出。

## 参考节拍（仅示例）

原作 10 秒，按片内秒。原作的关键时刻比半拍早约 0.1 秒（2.4、4.4、6.4）；新视频按 `CRAFT-005` 放到半拍上（如 2.5、4.5、6.5），其余节拍随之平移。

| 片内秒 | 手法 |
|---|---|
| 0–0.4 | CRT 开机；0.1–0.4 准星圆环从点扩到定位尺寸，其间 1 帧弧段错位、1 帧全屏提亮 |
| 0.4–1.9 | 日志逐行打字，行尾补 `[OK]`；弧段依次旋入；主体淡入并描出轮廓 |
| 2.4 | 状态胶囊切到搜索；大读数乱码解码约 0.25 秒后落定，之后缓慢递减 |
| 2.5–4.3 | 雷达扇带渐隐拖尾顺时针转一圈（约 2 秒一圈）；主体恒速自转 |
| 4.4 | 一帧故障；状态切到捕获；主体用约 1 秒 ease-in-out 转到目标朝向；候选列表每 0.5 秒比对一条 |
| 5.9–6.3 | 四个 L 括号带残影飞入，收拢成目标框；主体变暗 |
| 6.4–7.0 | 闪白、硬切琥珀、推近、弹回 |
| 7.3–7.8 | 坐标逐字打出，块光标闪烁，标注点淡入 |
| 7.4 / 7.9 / 8.4 | 端帽闪烁三次 |
| 8.5–9.75 | 静态保持 |
| 9.75–10 | CRT 关机 |

## 题材禁用清单

原作题材，新视频禁止出现，除非用户需求本身就是这些：地球与海岸线作为默认主体（只有用户题材与地理有关时才用球体）、长江口与坐标 `N31°14′ E121°29′`、「隼眼-9」「KESTREL-9」、城市名「盐城、扬州、金华、台州、温州」、`ORBIT LEO 512 KM`、候选代码 `BKK`/`URC`/`SHA`、`MATCH 99.7%`。主体、目标名、读数含义、日志内容全部来自用户题材。

## 技术配方

依赖：`gsap@3.15.0`、`three@0.186.1`（`HF-007`）。组合有 GSAP 时间线，Three.js 画布同时监听 `hf-seek`，两者在 0.8.96 上可以共存（本机实测）。

1. **图层**（从下到上）：Three.js `<canvas>`（主体与辉光）→ canvas 2D 数据层（波形、频谱柱等图形）→ SVG 仪表层（弧环、准星、刻度、括号）→ DOM 面板层（标签、读数、日志、十六进制数据流等全部文字）→ 闪白与 CRT 遮罩层。蜂窝底纹画在仪表圆以外，或在圆内用遮罩挖掉，不要压在发光主体上（reg-002-r3 实测会在扫描时露出六边形）。所有文字在最上面的 DOM 层；全屏 canvas 放在文字之上时，`check` 会把它当作不透明层，报每段文字被遮挡（reg-002 实测 51 个 error）。HUD 文字不进辉光通道，保持锐利。
2. **主体**：Three.js 用 `LineSegments` 画线框主体（`WireframeGeometry` 或自建经纬线），`LineBasicMaterial` 加 `AdditiveBlending`；`EffectComposer` 依次接 `RenderPass`、`UnrealBloomPass(new THREE.Vector2(1920, 1080), 0.8, 0.35, 0.6)`、`OutputPass`。本机实测这组参数下线框球画面近黑像素占比 93.5%；阈值降到 0.1 时只剩 27.6%，整屏发雾。背景色用 `scene.background = new THREE.Color(...)` 设，锁定后在 `renderAt` 里换成 `#080302`；禁止用 `renderer.setClearColor`：经 `OutputPass` 会被 sRGB 编码两次，`#010C0D` 变成 `#0D3D40`（blind-02 实测）。`renderAt(t)` 按 t 算主体旋转与颜色（锁定帧之后换琥珀），在 `hf-seek` 里调用（`HF-004`、`DET-005`）。
3. **配色切换**：颜色 token 在 JS 常量里定义一份，CSS 变量写同样的值；`drawHud` 等回调只读 JS 常量，禁止在回调里用 `getComputedStyle` 读 token（lint 会报 `gsap_callback_dom_measurement`）。面板配色的 CSS 变量按区域分组，例如 `--c-center`、`--c-top`、`--c-keep`。锁定时用 `tl.set(document.documentElement, { "--c-center": C.amber }, LOCK)` 切中心，`LOCK + 3/30` 秒再切 `--c-top`，`--c-keep` 不切。本机实测这种写法能在指定帧换色。
4. **逐帧内容**（乱码、波形、频谱、数据流、打字、倒计时）：用一个代理补间驱动重绘，时间取补间给出的 t：
   ```js
   const clock = { t: 0 };
   tl.to(clock, { t: DURATION, duration: DURATION, ease: "none", onUpdate: () => drawHud(clock.t) }, 0);
   ```
   `drawHud(t)` 里所有随机都用 `rng(Math.floor(t * 30))`（`DET-001`），打字用 `floor((t − t0) × 字符速率)`。
5. **弧环与准星**：SVG `<circle>` 配 `stroke-dasharray` 画弧段与虚线刻度，每层 `<g>` 用 GSAP 线性补间 `rotation`，各层速度与方向不同。
6. **锁定冲击**：闪白用满屏白色 `div`，在 `LOCK` 设为不透明度 0.85，下一帧设回 0；推近加在包住全部 HUD 的容器上：`tl.to(stage, { scale: 1.12, duration: D, ease: "power3.out" }, LOCK)`，再 `tl.set(stage, { scale: 1 }, LOCK + D)`，`D` 取 0.5 或 0.6，让弹回帧落在整帧上；放射残影用 5 份中心圆环副本，逐级放大 3%、不透明度递减。弹回帧的横向重影：中心圆环与锁定标题各复制 2 份（克隆节点或 SVG `<use>`），只在弹回那 1 帧显示，左右水平偏移 8–16px、不透明度 0.4，在抽帧上确认可见。禁止用整舞台的 CSS `drop-shadow` 做重影，它会被不透明的 WebGL 画布挡住（blind-02 实测）。
7. **CRT 开关机**：整幅舞台容器 `scaleY` 从 0.005 到 1（开机）或反向（关机），配一条亮横线 `div`，各约 0.3 秒。
8. **四角括号残影**：每个括号复制 3–4 份，与本体跑同一段补间，起点依次延后 0.02 秒、不透明度递减。

## 翻车点

- 做成粉紫霓虹渐变加城市夜景：这个风格是单色青，只在锁定时换一次琥珀
- 线条粗、有面填充或圆角卡片投影，看起来像普通后台仪表盘
- 辉光过曝把小字糊掉，或完全没有辉光
- 数据每帧 `Math.random` 乱跳闪烁；读数应有目标值并缓动收敛，补零且宽度固定
- 所有元素同时出现，没有开机、搜索、锁定的节拍
- 锁定没有打击感：缺闪白、硬切换色和推近，或用 1 秒渐变换色
- 中心用写实贴图或图标库图标，而不是线框
- 弧环全部同速同向旋转
- 锁定时全屏一起换色，没有中心先切、外围晚到

## 验收清单

在 `snapshot` 抽帧与成片联系表上逐项确认：

- [ ] 搜索阶段与保持阶段各抽一帧，亮度低于 20/255 的像素占 73–95%（`python <skill>/scripts/analyze.py dark <成片> --at <时刻>`）
- [ ] 小标签在 1080p 抽帧上清晰可读，没有被辉光糊掉
- [ ] 锁定帧前一帧为青色、锁定帧为闪白、之后中心为琥珀；底部次级模块仍为青色
- [ ] 读数补零、位宽不变，锁定后收敛到终值
- [ ] 首帧附近可见 CRT 开机，末帧附近可见 CRT 关机
- [ ] 音频在锁定帧有全片最响的起音，之后有三次间隔 0.5 秒的警报
- [ ] 画面与文字里没有「题材禁用清单」中的词
