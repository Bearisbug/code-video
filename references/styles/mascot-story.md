## 风格语法

### 叙事骨架

一个吉祥物角色贯穿全片，按「角色登场自我介绍 → 用户的问题场景 → 角色出手（输入 → 处理 → 产出）→ 问题解决的场景 → 片尾落版」推进。问题场景与解决场景用同一个布景，对照出前后变化。

### 配色

| hex | 角色 | 用在哪 |
|---|---|---|
| `#3B50B0` | 群青底 | 全片背景，占画面 70–85% |
| `rgba(100,124,224,.55)`、`rgba(92,114,216,.45)` | 光晕 | 左上与右下两团椭圆径向渐变，叠在群青底上 |
| `rgba(14,20,72,.5)` | 暗角 | 四角压暗 |
| `#F0E5CA` | 奶油 | 角色主体、字幕、星星、道具主体 |
| `#E5472F` | 番茄红 | 点缀：角色配饰、被子等布料、手绘标注线、编号角标、片尾光芒 |
| `#1D2766` | 墨蓝 | 眼睛、细节线、贴纸与书页上的字 |

用户有品牌色时按 `CRAFT-002` 替换；群青底与奶油主体的明暗结构保持不变。

### 质感

- **颗粒**：3 张预生成的噪点图按 12fps 循环切换；暗颗粒 `rgb(18,26,84)` 约占 7.5% 像素，亮颗粒 `rgb(255,246,226)` 约占 6.5%，整层盖在所有内容之上。
- **线条抖动**：`feTurbulence` + `feDisplacementMap` 做成滤镜，图形位移 7px、字幕与标注位移 4px；噪声种子每秒换 8 次，在 6 个种子之间循环，读作手绘线条的沸腾。
- **角色表面**：奶油底上带墨色斑点纹理，脸颊两团淡红腮红。
- **背景常驻元素**：约 54 颗星星（十字与圆点两种），各自按不同频率正弦闪烁；四角取景框线在开场 0.7 秒内描出；底部一条沿波浪基线循环滚动的关键词跑马灯，速度 70px/s，小字。

### 图元

- 角色：圆润的简单剪影（圆、胶囊），墨蓝点状眼睛，可切换笑眼；可以带一个配饰（帽子、围巾等）。身高约占画面 25–30%，脚下有随高度缩放的椭圆投影。
- 道具：扁平圆角剪影，奶油或番茄红，墨蓝细节。
- 思维气泡：虚线椭圆，外加从小到大 3 个圆点。
- 便签贴纸：奶油纸条，墨蓝等宽字，左上角红色圆形编号角标，轻微倾斜 −5° 到 4°。

### 字体

| 片尾名称 | Courier Prime 700，字距 4px | 156px |

### 运动

| 项 | 数值 |
|---|---|
| 字幕 | 逐字打出，每秒 14–34 字（短句慢、长句快）；打完 0.12 秒后用 0.48 秒 ease-out 画出红色手绘标注，起画时刻取打完 0.12 秒后的第一个半拍网格点（`CRAFT-005`），配的 `tick` 与起画同帧；字幕在结束前 0.25 秒淡出 |
| 手绘标注 | 两种：圈（不规则椭圆，首尾交叠约 0.55 弧度，整体倾斜 −0.05）或波浪下划线（振幅 5px，波长 34px）；红色 7px 圆头线，片尾名称用 10px |
| 角色登场 | 从画面上方以回弹（bounce）落下 0.8 秒，再弹性放大（阻尼余弦）到原尺寸 0.95 秒；配饰晚 0.35 秒以回弹落到头上、旋转回正 |
| 角色待机 | 上下浮动 6px，正弦 2.4 rad/s；眨眼每次 0.09 秒；视线左右扫 0.2 秒 |
| 角色退场 | back-in 缩小到 0，同时旋转 −25°，0.4–0.45 秒 |
| 角落探头 | 从画面外以 back ease 升起 0.55 秒，缩到 0.36 倍，旁边弹出一个红色惊叹号 |
| 吞下、惊喜 | 挤压拉伸衰减正弦 3 个周期，振幅 0.16，0.6 秒；伴随 8 个放射火花 |
| 道具 | 逐个以 back ease 弹出，间隔 0.12–0.33 秒；飞入角色时走二次贝塞尔抛物线，同时缩到 0.12 倍并旋转 |
| 翻书、翻牌 | `scaleX = cos(π·进度)`，过零时切换正反面 |
| 片尾光芒 | 18 根红色放射线从角色外沿依次伸出，每根错开 0.018 秒，整体以 7°/s 缓慢旋转，长度随正弦轻微脉动 |

缓动库：cubic out/in/in-out、back（1.70158）、back-in、弹性（`1 − 2^(−11x)·cos(4.5πx)`）、回弹（标准 bounce）。

### 镜头

固定正面 2D 机位，不推拉、不摇移。场景之间靠角色退场加新场景元素弹出衔接，前后交叠 0.3–0.4 秒。

### 声音

原作没有音轨，以下是建议配置，其中音床与 `impact` 的 `gain` 经 blind-05 实测：`synth.py` 的 `pluck` 音床 100 BPM，大调和弦，`gain` 1.0；角色落地 `pop`，道具弹出 `pop`（`gain` 0.4–0.6），字幕打字不加音效，标注画出配一声 `tick`，吞下配 `whoosh`，片尾光芒展开配 `chime`，片尾名称落定配全片最响的 `impact`（`gain` 0.8）并在其前留空拍（`AUD-003`）。音床 0.5、`impact` 1.0 时归一化会进入 dynamic 模式。

## 参考节拍（仅示例）

原作 20 秒，只借节奏与手法，角色、道具、剧情、文案按用户题材换掉。新视频按 `CRAFT-005` 把事件放到半拍网格上。

| 片内秒 | 手法 |
|---|---|
| 0–0.7 | 取景框线描出，星星逐颗亮起 |
| 0.15–2.05 | 角色从上方回弹落下、弹性放大、配饰落到头上、睁眼 |
| 1.9–4.55 | 字幕「自我介绍」逐字打出，名字被红圈圈出；角色眨眼、左右看 |
| 4.45–4.9 | 角色旋转缩小退场 |
| 5.0–9.9 | 问题场景：布景弹入，道具依次弹出，字幕里的关键数字加波浪下划线；思维气泡里循环一个小动作（计数递增） |
| 8.55–10.0 | 角色从画面角落探头，弹出红色惊叹号 |
| 10.0–12.4 | 角色移到画面左侧；三张便签贴纸依次弹出，飞进角色，角色挤压拉伸并迸出火花 |
| 12.35–15.2 | 产出物弹出并展开（翻开、立起），里面的文字逐字打出 |

## 题材禁用清单

原作题材，新视频禁止出现，除非用户需求本身就是这些：戴睡帽的月亮脸角色、失眠与数羊、夜里 11 点、「给角色三个词、角色吞下后变出故事书」的桥段（「道具飞进角色、角色处理后变出结果」这个手法可以用，禁的是三个词与故事书这组具体内容）、立体故事书、小龙、原作的台词与标语、原作的跑马灯词组。角色造型、名字、道具与台词全部来自用户题材。

## 技术配方

依赖：`gsap@3.15.0`（只用来驱动时钟）。整个画面由一个纯函数 `render(t)` 算出，每个场景一个 `renderX(t)`。组合契约见 `HF-004`。以下写法在 0.8.96 上用原作源码移植实测：600 帧，`check` 通过，字体下载 0。

1. **时钟**：字体加载完、依赖布局测量的初始化做完之后，再建时间线并注册：
   ```js
   (async () => {
     await document.fonts.ready;
     buildAnnots();              // 需要测量文字位置的初始化放在这里
     render(0);
     const clock = { t: 0 };
     const tl = gsap.timeline({ paused: true });
     tl.to(clock, { t: DUR, duration: DUR, ease: "none", onUpdate: () => render(clock.t) }, 0);
     window.__timelines["main"] = tl;
   })();
   ```
2. **时间窗口与缓动**：每个动作写成「窗口进度 → 缓动 → 属性」，不累积状态（`DET-004`）。顶层工具函数用 `function` 声明：写成不带花括号的 `const P = (…) => …;` 时，`check` 截取函数体会越过分号，把后面测量文字位置的代码算进去，`render` 调用它就被报 `gsap_callback_dom_measurement`（blind-05 实测）：
   ```js
   function clamp(x, a = 0, b = 1) { return x < a ? a : x > b ? b : x; }
   function P(t, a, b) { return clamp((t - a) / (b - a)); }   // t 在 [a, b] 内的进度
   const E = {
     out: x => 1 - (1 - x) ** 3,
     io: x => x < .5 ? 4 * x ** 3 : 1 - (-2 * x + 2) ** 3 / 2,
     back: x => { const c = 1.70158; return 1 + (c + 1) * (x - 1) ** 3 + c * (x - 1) ** 2; },
     bin: x => { const c = 1.70158; return (c + 1) * x ** 3 - c * x ** 2; },
     el: x => x <= 0 ? 0 : x >= 1 ? 1 : 1 - 2 ** (-11 * x) * Math.cos(x * Math.PI * 4.5),
   };
   function blink(t, times, d = .09) {                      // 在给定时刻眨眼，返回眼睛的纵向缩放
     return times.reduce((m, bt) => Math.min(m, Math.abs(t - bt) < d ? Math.max(.08, Math.abs(t - bt) / d) : 1), 1);
   }
   ```
3. **线条抖动**：两个滤镜，图形用 `wob`（`baseFrequency 0.014`、`scale 7`），字幕与标注用 `wob2`（`0.02`、`4`），`feTurbulence` 都带 `class="wobT"`；在 `render(t)` 开头按帧换种子：`const seed = 1 + Math.floor(t * 8) % 6;`，种子变化时才改 `seed` 属性。
4. **颗粒**：用带种子的伪随机（`DET-001`）生成 3 张 960×540 的 canvas，拉伸到 1920×1080、`image-rendering: pixelated`；`render(t)` 里只显示第 `Math.floor(t * 12) % 3` 张。canvas 的 CSS 设 `opacity: .5`，像素 alpha 取目标值的 2 倍（暗颗粒 240、亮颗粒 116）。原因：版面检查把不透明度不低于 0.6 的 canvas 当作不透明遮挡物，会把所有文字报成 `text_occluded`；设为 0.5 后不算遮挡物，合成后的画面不变。
5. **字幕与标注**：每个字包一个 `<span>`，可见字数 `n = Math.floor((t - t0) * cps)`；要标注的词包在一个外层 `<span>` 里，字体加载后用 `offsetLeft/offsetWidth` 量出位置，生成一条 `pathLength="1"`、`stroke-dasharray="1 2"` 的 SVG 路径，按进度改 `stroke-dashoffset` 画出。圈与波浪线的生成：
   ```js
   function ringPath(cx, cy, rx, ry) {
     const pts = [], a0 = -Math.PI * .8, span = Math.PI * 2 + .55, tilt = -.05;
     for (let i = 0; i <= 72; i++) {
       const u = i / 72, a = a0 + span * u, k = 1 + .035 * Math.sin(3 * a + 1.3) + .07 * u;
       const x = Math.cos(a) * rx * k, y = Math.sin(a) * ry * k;
       pts.push(`${cx + x * Math.cos(tilt) - y * Math.sin(tilt)} ${cy + x * Math.sin(tilt) + y * Math.cos(tilt)}`);
     }
     return "M" + pts.join(" L");
   }
   function wavePath(x0, x1, y) {
     let d = `M ${x0} ${y}`;
     for (let x = x0 + 4; x <= x1; x += 4) d += ` L ${x} ${y + 5 * Math.sin((x - x0) / 34 * 2 * Math.PI)}`;
     return d;
   }
   ```
   圈的尺寸：`rx = 词宽/2 + 字高×0.42`，`ry = 字高×0.62`；波浪线在词下方 `字高×0.98` 处，左右各伸出 6px。
6. **跑马灯**：SVG `<textPath>` 沿一条二次贝塞尔拼成的波浪路径排字，`startOffset = 1500 - t * 70`。
7. **字体**：只写登记表里的家族与通用族，例如 `font-family: "Courier Prime", monospace`，按 `FONT-001` 内联 `@font-face`。字体栈里不要写 `"Courier New"` 这类系统字体名：HyperFrames 会把它映射成替代字体并在渲染时联网下载（移植实测）。
8. **背景**：群青底与两团光晕、四角暗角直接写在组合根的 CSS `background` 上，用多层 `radial-gradient`。

## 翻车点

- 角色做成写实或复杂插画：这个风格是圆润的简单剪影，加点状眼睛
- 颜色超过「群青 + 奶油 + 番茄红 + 墨蓝」四色，或者底色换成渐变色块
- 没有颗粒或线条抖动，画面发干，像普通扁平 PPT 动画
- 颗粒每帧都换（太闪）或完全不换（像贴图）；应为 12fps 循环 3 张
- 字幕整句一起淡入，没有打字与手绘标注
- 角色动作只有位移和淡入淡出，没有回弹、弹性、挤压拉伸和眨眼
- 场景之间硬切，没有角色退场与元素弹入的衔接
- 问题场景与解决场景用了不同布景，看不出前后对照

## 验收清单

在 `snapshot` 抽帧与成片联系表上逐项确认。颗粒 12fps 换张、线条每秒换 8 次种子，整幅画面每 2–3 帧就变一次，`analyze.py motion` 与 `sync` 的画面侧测不准（blind-05 实测）：`flow-verify.md` 第 2、4 步的节拍与同步改用逐帧拼图目检，音频侧照常用 `analyze.py onsets` 核对起音。

- [ ] 背景是群青加光晕与暗角，颗粒可见且不闪烁成白噪
- [ ] 角色贯穿全片，登场有回弹落下与弹性放大，至少一次眨眼
- [ ] 至少一句字幕是逐字打出的，关键词有红色手绘圈或波浪线
- [ ] 问题场景与解决场景使用同一布景
- [ ] 片尾有放射光芒、名称圈注与标语
- [ ] `check` 通过（全屏颗粒层没有触发 `text_occluded`），`.hf-font-cache/` 为空
- [ ] 画面与文字里没有「题材禁用清单」中的元素
