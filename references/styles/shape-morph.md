# shape-morph · 一形贯穿形变（Shape Morph）

| 字段 | 值 |
|---|---|
| id | `shape-morph` |
| 渲染层 | HyperFrames · SVG/DOM（GSAP + MorphSVGPlugin） |
| 画幅 | 16:9；9:16 可用，图形与字幕按竖屏重新居中 |
| 时长 | 默认 10 秒，可用 8–15 秒 |
| BPM | 120 |
| 适用用途 | 品牌片头与字标演绎、产品理念 10–15 秒短片、功能图标串讲、节日与情绪短视频、章节转场 |
| 状态 | 草稿，未盲测 |
| 证据 | 第三方风格合集视频（作者未确认）中「形变动画」一段的逐帧拆解（风格卡 + 独立核验，记录在作者未公开的工作区）；本包的数值均取自核验后的观察值，实现方式为推断 |

## 风格语法

### 配色

每个场景用一种主底色加一种主图形色，底色在下表的底色里轮换，相邻场景不重复。地平线类构图可以上下各用一块底色。

| hex | 角色 | 用在哪 |
|---|---|---|
| `#E5E0D6` | 米白纸 | 底色；带纸纹 |
| `#F3EEE4` | 纸白 | 图形色、中间态团块、字标字母；带纸纹 |
| `#14141A` | 墨黑 | 图形色、浅底上的字幕 |
| `#EFA923` | 明黄 | 底色、图形色 |
| `#EE4A27` | 橙红 | 底色、图形色 |
| `#2034DA` | 群青蓝 | 底色、图形色 |
| `#131317` | 近黑 | 收尾底色 |
| `#F74B26` | 强调红 | 只用于收尾的句点与副标分隔点 |

图形内最多加一块斜切的同色系明暗面：亮一档、暗一档，或半透明浅色折角三选一。

### 质感

- 纸纹只挂在米白底与纸白图形上，亮度起伏约 ±3，整片静止不闪烁；高饱和底色、近黑底、墨黑图形保持平涂。
- 舞台四角压暗 9–12%。
- 落地的图形可以带一块低对比、柔边的灰色接触阴影椭圆。
- 禁用渐变、描边、硬偏移投影、拟物高光。

### 图元

- 主图形是圆角实心剪影，居中，高度占画面 20–30%，四周大量留白。任何时刻画面上只有一个主图形。
- 附属件（气流、光线、倒影、轨迹、涟漪、落地线）画成圆头粗线或虚线，需要时长出，用完收回。上一场景留下的线条可以带进下一场景，再缩回新图形底部。

### 字体

| 元素 | 字体（见 `fonts.md`） | 1080p 字号 |
|---|---|---|
| 场景编号「NN/总数」 | JetBrains Mono 700，总数降低到 40% 不透明度 | 36px（装饰性） |
| 场景名（两个汉字） | Noto Sans SC 900 | 44px |
| 场景英文名 | JetBrains Mono 400，全大写，字距 0.3em | 20px（装饰性） |
| 收尾字标（拉丁字母） | Outfit 800，全小写；有品牌母版时用母版路径（`CRAFT-008`） | 160px |
| 收尾字标（中文） | Noto Sans SC 900；有品牌母版时用母版路径（`CRAFT-008`） | 160px |
| 收尾副标 | Noto Sans SC 500，字距 0.4em；英文行用 JetBrains Mono 全大写 | 44px / 20px（英文行装饰性） |

字幕放左下角安全区内，颜色按底色取下表，对比度均不低于 4.5:1（`check` 的对比度检查按这个门槛）。右下角放圆点页码，当前页拉成长条。

| 底色 | 字幕色 | 对比度 |
|---|---|---|
| 米白 `#E5E0D6` | 墨黑 | 13.95 |
| 明黄 `#EFA923` | 墨黑 | 9.06 |
| 橙红 `#EE4A27` | 墨黑 | 4.93 |
| 群青蓝 `#2034DA` | 纸白 | 7.08 |
| 近黑 `#131317` | 纸白 | 16.03 |

橙红这一格只比 4.5 高 0.43，叠上暗角后可能跌破门槛（reg-004-r2 在英文小字处实测 4.38:1，`check` 报警）。带字幕的橙红场景以 `check` 的对比度结果为准，报警时把这一场换成米白或明黄底。

### 运动

| 项 | 数值 |
|---|---|
| 每个场景 | 1.0–1.5 秒，取半拍的整数倍（120 BPM 时为 1.0、1.25、1.5 秒），全片至少混用两种；其中形变 0.2–0.3 秒，其余是停留。原作每场景 1.1–1.3 秒，不在半拍网格上，按 `CRAFT-005` 对齐。字幕可见要满 `CRAFT-004` 的 1 秒，排法见「字幕切换」一行 |
| 形变路径 | 一律两段：A → 椭圆团块 → B；前段 `power2.in`，后段 `back.out(1.7)`，约 8% 过冲 |
| 挤压拉伸 | 下落时纵向拉长到约 1.4 倍；触地压扁到 scaleX 1.3、scaleY 0.7，再用 `elastic.out(1, 0.4)` 回到 1，约 0.35 秒 |
| 停留时的二级循环 | 周期 0.2–0.4 秒，按图形选一种：摆动、旋转、扑动、搏动、扩散；画面不静止 |
| 换底色 | 圆形揭示：圆心取当前图形中心或落点，0.15–0.25 秒铺满，`power2.in`，边缘柔化；地平线类改用水平分界线升降。0.2 秒的揭示要比拍点提前 4 帧起步，新底色铺开大半的那一帧落在拍点上（`AUD-002`） |
| 快速位移 | 身后拖 8 个等距残影，不透明度从 0.5 逐个递减 |
| 字幕切换 | 形变完成后 0.05–0.1 秒直接换成新场景的字幕。前后两个底色的字幕色相同时（米白、明黄、橙红都配墨黑），揭示直接扫过字幕、不淡出，字幕可见时长约等于场景时长。字幕色要变的那一次，旧字幕必须在揭示扫到字幕区之前淡出（0.1 秒），1.25 秒的场景里只剩约 0.75 秒可见：把这次换色排在一段无字幕的快速位移之后，让旧字幕在位移段里淡出；或者按帧号逐个核对，可见帧数不少于 30 |
| 收尾 | 约 1.8 秒，见参考节拍 |

### 镜头

固定正交 2D 机位，全程没有推拉摇移、视差和 3D。

### 声音

`synth.py` 的 `pluck` 音床，120 BPM，`start` 取 0.5（半拍网格上），结尾 0.5 秒淡出。每次形变卡一个音效：落地 `pop`，形变 `whoosh`（`dur` 0.25），快速位移 `whoosh`（`dur` 0.4），底色揭示 `impact`。全片最强揭示的 `impact` 取 `gain` 1.0，其余揭示取 0.4–0.6；最强揭示前的低谷与之后音床抬高一档都写进 `bed.automation`（`AUD-003`）；低谷窗口里不放形变音效，那一次形变只配揭示的 `impact`。搏动类循环每下配一个 `impact`，`gain` 0.4。音床 `gain` 取 0.75–0.95：取默认 0.5 时归一化会进入 dynamic 模式（两次回归实测）。`whoosh` 的 `gain` 不超过 0.3：噪声的真峰值比采样峰值高得多，reg-001-r3 实测采样峰值 −3.0 dBFS 时真峰值 −0.5 dBTP。

## 参考节拍（仅示例）

原作 10 秒、7 个场景加字标收尾。只借用节奏与手法，物件和文案按用户题材换掉。

| 片内秒 | 手法 |
|---|---|
| 0.0–0.3 | 空白 |
| 0.2–0.65 | 第一个图形从画面顶部落下，纵向拉长；0.55 触地压扁，配 `pop` |
| 0.65–1.4 | 经团块变成场景 1 图形，附属线条长出并做二级循环；左下字幕出现 |
| 约每 1.2 秒 | 进入下一个场景：形变 0.25 秒，同时或随后做一次底色圆形揭示 |
| 5.3–6.3 | 一次快速位移：带残影冲刺、绕环 |
| 6.3–6.6 | 全片最强揭示：揭示前留约 0.1 秒音量低谷，新底色铺开的那一帧落 `impact` |
| 8.2–10.0 | 收尾：近黑圆从最后一个图形中心扩张铺满；团块向右弹跳，每次落地弹出一个字标字母；各场景颜色化成一串短线汇成强调红句点；副标淡入；句点外扩一圈细圆环后定格 |

## 题材禁用清单

原作题材，新视频禁止出现，除非用户需求本身就是这些：墨滴、咖啡杯与蒸汽、太阳与日出日落、海鸥、纸飞机、定位针、爱心；字标「morphe.」；副标「一形 · 万象」「ONE SHAPE · EVERY STORY」；场景名「早安、日出、日落、海风、远行、抵达、心动」。开场的第一个图形取自用户题材的第一个物件，不默认用水滴。用户的品牌与原作物件同品类时（例如咖啡品牌），禁的是原作的具体造型与出场顺序：同品类物件可以使用，但要换造型、换顺序。

## 技术配方

依赖：`gsap@3.15.0`（包内含 MorphSVGPlugin，标准许可允许商用）。组合契约见 `HF-004`。

1. **图层**：一个 `<svg viewBox="0 0 1920 1080">` 从下到上依次为：底色矩形 → 揭示层（新底色矩形，用 `mask` 里的圆裁出）→ 附属线条组 → 残影组 → 主图形组 `<g id="heroWrap"><path id="hero"/></g>`；字幕与页码放在 SVG 之上的 DOM 层；最上面一层是暗角。
2. **形状**：每个场景的剪影写成一条闭合 `<path>`，放进一个 `display:none` 的 `<g>`，另画一条椭圆团块 `<path id="blob">`。所有路径用同一坐标系：以画面中心为原点、高约 280px。
3. **形变**：`gsap.registerPlugin(MorphSVGPlugin)`；每次形变写成两段：
   ```js
   tl.to("#hero", { morphSVG: "#blob", duration: 0.12, ease: "power2.in" }, T)
     .to("#hero", { morphSVG: "#s2", duration: 0.15, ease: "back.out(1.7)" }, T + 0.12)
     .to("#hero", { fill: C.yellow, duration: 0.2 }, T);
   ```
   颜色取自 JS 常量 `C`（与 CSS token 同值，`CRAFT-006`）。会被补间颜色的元素，初始颜色在创建时间线之前用 `gsap.set("#hero", { fill: C.ink })` 设一次，不要写成 CSS `var(--c-yellow)`：GSAP 会把变量名里的 `yellow` 当颜色名解析，补间从 `#FFFF00` 起步（blind-01 实测）。不要用时间线上第 0 秒的 `tl.set`，lint 会报 `gsap_timeline_set_initial_hide`（reg-001 实测）。
4. **挤压拉伸**：变换加在 `#heroWrap` 上，`transformOrigin: "50% 100%"`，形变只加在 `#hero` 上，两者互不覆盖。SVG 元素的百分比原点按包围盒计算，形变会改变包围盒，所以在 `#heroWrap` 里放一个固定尺寸的透明 `<rect>` 当锚点，让包围盒不随形变变化（blind-01 用这个写法）。
5. **圆形揭示**：`<mask id="reveal"><circle id="revealC" r="0" fill="#fff" filter="url(#soft)"/></mask>`，`#soft` 为 `feGaussianBlur stdDeviation="12"`；揭示时先 `tl.set` 圆心到当前图形中心，再把 `attr: { r: 2203 }`（画面对角线长度）补间 0.2 秒；揭示结束后用 `tl.set` 把底色矩形改成新色、半径归零。
6. **二级循环**：用有限次重复写，`repeat` 按停留时长算（`DET-001`），例如 `tl.to("#steam", { y: -6, duration: 0.15, yoyo: true, repeat: 3, ease: "sine.inOut" }, T)`。
7. **残影**：复制 8 份主图形到残影组，各自跑与主图形相同的位移补间，第 k 份起点延后 `k × 0.012` 秒、不透明度 `0.5 × (1 − k/8)`，冲刺结束时整组淡出。
8. **纸纹**：只给填充为米白、纸白的元素加 `filter="url(#paper)"`。下面这段在 0.8.96 上实测：米白底高频亮度标准差 2.66，群青底为 0（平涂）：
   ```html
   <filter id="paper" x="0" y="0" width="100%" height="100%">
     <feTurbulence type="fractalNoise" baseFrequency="0.8" numOctaves="2" seed="7" result="n"/>
     <feColorMatrix in="n" type="saturate" values="0" result="g"/>
     <feComponentTransfer in="g" result="g2">
       <feFuncR type="linear" slope="0.3" intercept="0.7"/>
       <feFuncG type="linear" slope="0.3" intercept="0.7"/>
       <feFuncB type="linear" slope="0.3" intercept="0.7"/>
     </feComponentTransfer>
     <feComposite in="g2" in2="SourceGraphic" operator="in" result="gc"/>
     <feBlend in="SourceGraphic" in2="gc" mode="multiply"/>
   </filter>
   ```
9. **暗角**：顶层 `div` 背景为 `radial-gradient(ellipse at center, transparent 55%, rgba(0,0,0,0.11) 100%)`。
10. **字标收尾**：字母用 DOM 文字（拉丁字母 Outfit 800，中文 Noto Sans SC 900；有品牌母版时按 `CRAFT-008` 换成母版路径，落点取各字在母版里的位置），每个字符在团块落地的那一帧从 `scale: 0` 以 `back.out(2)` 弹到 1；团块每跳 0.125 秒（120 BPM 的十六分音符；按 `CRAFT-005` 逐个向下取帧，30fps 下从整拍起跳的间隔为 3、4、4、4 帧，从半拍起跳为 4、4、3、4 帧），落点间距等于字母宽度。句点是强调红圆，细圆环用 `stroke` 圆的 `attr: { r }` 从句点半径扩到 +40px，同时不透明度 1→0，历时 0.6 秒。

## 风格提示词

```text
做一支 {时长} 秒、{画幅}、30fps 的「一形贯穿」形变动画，主题是 {主题}。
画面任何时刻只有一个扁平圆角剪影，它依次变成 {N} 个与主题相关的物件：{物件1} → {物件2} → … → {物件N}，串成一条有先后关系的小故事，最后逐字弹出字标「{字标}」并定格。
配色只用 shape-morph 风格包的色板：每个场景一种主底色加一种主图形色，相邻场景底色不重复；纸纹只挂在米白底与纸白图形上；四角压暗约 10%。
每个场景约 1.2 秒，形变 0.25 秒且必须经过椭圆团块中间态，落点带约 8% 过冲；下落拉长 1.4 倍、触地压扁到 0.7 倍再回弹；停留时跑 0.2–0.4 秒周期的二级循环；换底色用从图形中心扩张的圆形揭示，0.2 秒铺满。
左下角字幕：等宽数字「NN/总数」、两字中文场景名 {场景名列表}、宽字距英文小字；右下角圆点页码。
固定正交机位，不推拉、不透视。
声音：明亮拨弦音床 120 BPM，落地配 pop，形变配短 whoosh，最强揭示前留 0.1 秒空拍再落低频冲击。
```

## 翻车点

- 用透明度叠化两个图形冒充形变，轮廓没有连续变化
- 拓扑差异大的两个形状直接 A→B 插值，不经过团块中间态，中途打结
- 给图形加渐变、描边、硬投影或高光
- 一个场景出现三种以上主色，或底色选了低饱和灰调
- 全局铺纸纹，把高饱和色块弄脏
- 所有场景停留时长完全相等，运动是线性匀速，没有挤压拉伸和过冲
- 底色用硬切或整屏淡入淡出切换
- 图形停下后完全静止
- 加入推拉摇移、视差或 3D

## 验收清单

在 `snapshot` 抽帧与成片联系表上逐项确认：

- [ ] 任一帧只有一个主图形，形变中间帧能看到团块形态
- [ ] 每个场景底色与图形色取自色板，相邻场景底色不同
- [ ] 米白、纸白区域有纸纹，高饱和底色是平涂
- [ ] 至少一次圆形揭示，圆心在图形中心或落点
- [ ] 落地帧可见压扁形态
- [ ] 字幕在左下安全区内，颜色按字幕配色表取，字号不小于字体表数值；`check` 的对比度检查全部通过
- [ ] 收尾字标逐字出现并定格，句点为强调红
- [ ] 画面与字幕里没有「题材禁用清单」中的词
