## 风格语法

### 配色

黑白灰加一个强调色。底色占画面大半，元素小、留白大；不用渐变、暗角、纹理。

| hex | 角色 | 用在哪 | 对底色对比度 |
|---|---|---|---|
| `#F7F7F4` | 底色 | 全片背景 | — |
| `#ECECE8` | 第二底色 | 卡片下的凹槽、远景点阵 | 1.10 |
| `#FFFFFF` | 卡片 | 界面窗口、卡片、图解部件，靠柔和投影与底色分开 | 1.07 |
| `#E2E2DD` | 细线 | 卡片描边、分隔线 | 1.21 |
| `#6E6E69` | 次要文字 | 标签、副标、被压暗部件的标签 | 4.78 |
| `#161616` | 主文字 | 标题、字幕、图解描边与连线、光标 | 16.86 |
| `#1A7F52` / `#B42323` / `#2F5BD3` | 强调（可作文字） | 三选一，每支片只用一个；作文字时只用于一个强调词或关键词标签 | 4.66 / 6.10 / 5.50 |
| `#17A05E` / `#D9542B` | 强调（只上图形） | 勾、点、进度线；与上一格同色系配对（绿配绿、红配红橙；选蓝色时图形也用 `#2F5BD3`），禁止作文字 | 3.14 / 3.72 |
| `#131317` | 落版底色（可选） | 黑底落版，其上文字只用底色 `#F7F7F4`（17.27） | 17.27 |

- 底色占比：按 `analyze.py ground` 的口径，中位帧的底色占比不低于 0.70。实测界面类浅底片 0.73–0.98（motion-web 0.98、skill-demo 0.96、knockon 0.82、发布片 0.73），本包两个探针 0.99、0.98。
- 品牌色按 `CRAFT-002` 替换相对亮度最接近的一格（多为「强调」那一格），替换后作文字的格仍须不低于 4.5:1。

### 运动

| 项 | 数值 |
|---|---|
| 开场词 | 逐个弹入，间隔 0.5 秒（120 BPM 一拍，落在 `CRAFT-005` 的半拍网格上）；透明度 0.15 秒先到位，位移 40px 与缩放 0.96→1 走弹簧（阻尼比 0.5、角频率 14，补间 0.9 秒） |
| 字标字母 | 逐字间隔 0.055 秒，0.28 秒 `power2.in` 落下，触地 0.06 秒压成 scaleX 1.12、scaleY 0.82，再按弹簧（0.45、30）回到 1 |
| 打字 | 中文每秒 12 字，拉丁每秒 28–38 字符，字数取 `floor((t − t0) × 速率)` |
| 光标 | 移动 0.8 秒 `power3.out`；点击时指针缩到 0.84 倍，按下到抬起 0.07 秒（30fps 约 2 帧） |
| 容器变形 | 0.5 秒 `expo.inOut`，同时补间宽、高、x、y 与圆角；位移超过约 170px 时峰值超过 80px/帧，按 `CRAFT-013` ③ 改成 0.8 秒 `power2.inOut`（位移 640px 以内不超阈值） |
| 打勾 | 勾从 0.8 倍弹到 1（弹簧 0.5、26，补间 0.35 秒） |
| 快切单词 | 每个 0.25 秒（可用 0.22–0.36），硬切 |
| 开关、标题栏这类界面部件落位 | 弹簧阻尼比 0.5–0.7、角频率 26–42 |
| 落版 | 动作结束后完全静止不少于 2.0 秒 |

缓动分两类混用，禁止通篇一种：到位用快照曲线或弹簧（t80 ≤ 0.33：`expo.out` 0.23、`back.out(1.7)` 0.24、`power3.out` 0.33），镜头与容器变形用对称曲线（`sine.inOut` 0.70、`expo.inOut` 0.57）。t80 的定义见 `CRAFT-015`。

### 镜头

两种做法二选一，写进选定构思（`CRAFT-009`），一支片里不混用：

- 固定机位，元素自己承接分界（容器变形、元素滑进下一个容器）；
- 一镜到底跟拍：舞台容器做推近、跟拍与落地抖动，参数按 `CRAFT-012`。本包取值：推近 1.0–1.4 倍（图解放大进入内部 2–2.5 倍），关键帧比主体早 0.1 秒，手持浮动 4px，全片最重要的落地抖动 8px、衰减率 10、9Hz，带界面文字的段落 4px。

### 节奏与段落

`CRAFT-010` 全部适用，本包不设例外。发布片的段落骨架（推断，取自下面参考节拍的时间结构）：

| 段 | 10–15 秒片 | 20–45 秒片 |
|---|---|---|
| 钩子：一句话或一个动作 | 1.5–2 秒 | 2–3 秒 |
| 产品亮相：界面或标志第一次出现 | 2–3 秒 | 3–5 秒 |
| 功能拍：每拍一个操作特写（`CRAFT-016`） | 1–2 拍，各 1.5–3 秒 | 3 拍，各 3–6 秒 |
| 收束：停顿或快切 | 1–1.5 秒 | 2–4 秒 |
| 落版：标志 + 不超过 1 行价值句（有出处，`CRAFT-018`）+ 可选 1 行获取方式（只在用户材料里有时放） | 不少于 2.5 秒，其中静止不少于 2.0 秒 | 不少于 3 秒 |

### 图解（科普讲解用）

- 部件：卡片色填充，3px 主文字色描边，圆角 24px；连线 5px 主文字色圆头线，带箭头，用 `pathLength="1"` 加 `stroke-dashoffset` 画出。
- 标签贴在部件下方约 30px，44px；关键词标签用文字可用的那一格强调色。
- 比喻本身靠颜色区分时（如调颜料），这些颜色按 `CRAFT-002` 的题材固有色加入，只上图形、不上文字；文字仍只用主文字、次要文字与一格强调色。
- 只亮当前部件：其余部件与连线降到 40% 不透明度；被压暗部件的标签不降透明度，改成次要文字色。主文字色降到 40% 后在底色上只有 2.53:1，而 `check` 的对比度检查查不出来（实测 15/15 照样通过）。
- 放大进入内部：镜头推近 2–2.5 倍，内部零件随后出现；零件标签的屏幕字号 = 原字号 × 推近倍数，不小于 44px（22px × 2.2 = 48px）。
- 四种图解动作（逐步搭建、只亮当前、放大进入、拆分合并）见 `CRAFT-017`。

### 声音

`synth.py` 的 `pluck` 音床，120 BPM，`drums: false`，开启共用空间 `"space": {"t60": 1.1}`（`AUD-006`），`bed.send` 写 0（`AUD-003`）。音床从第一个大转折（产品亮相）进入，`start` 取那一拍，此前只有动作声。增益按 `AUD-005`：音效密集的发布片音床 1.25、全片最响落地 `impact` 1.0；音效稀疏的科普片按「轻」一档（`CRAFT-017`）。

| 画面事件 | 音效 |
|---|---|
| 开场词弹入 | `pop` 0.4，音高逐词升（1、1.12、1.26） |
| 打字 | 每 3 个字一声 `tick` 0.15 |
| 点击 | 按下 `tick` 0.3、抬起 `tick` 0.2，相隔 2 帧（67ms），与画面同帧 |
| 容器变形 | `whoosh`，`dur` 0.5、gain 0.25，`t` = 变形中点 − 0.25 |
| 打勾 | `pop` 0.45，`pitch` 1.5 |
| 快切单词 | 每词 `impact` 0.35，`pitch` 1.4 |
| 全片最重要的落地（字标） | `impact` 1.0 叠 `pop` 0.4；前 0.1 秒音床压到 0.03（`AUD-003`） |
| 停顿段 | 一口气之后完全安静：`bed.automation` 在停顿段压到 0.03 |

音乐不得盖住动作声：按 `AUD-005` 的方法测，起音型音效比音床高 3 dB 以上（blind-06 起音型取 0.35–0.45 时 Δ 3.3–3.4 dB）。

## 技术配方

依赖：`gsap@3.15.0`。组合契约见 `HF-004`。以下写法在 0.8.96 上实测：10 秒发布片探针 300 帧，`check` 通过（对比度 13/13），`render --strict --workers 2` 成片帧数精确、字体下载 0；6 秒图解探针 180 帧，`check` 通过（对比度 15/15）。

1. **图层与 token**：根元素背景是底色；一个舞台容器 `#cam`（`position:absolute; left:0; top:0; width:1920px; height:1080px; transform-origin:0 0`）包住所有随镜头运动的元素；快切单词与落版放在 `#cam` 外，不随镜头缩放。配色在 `:root` 定义一次，JS 常量写同样的值（`CRAFT-006`）。卡片投影：`box-shadow: 0 1px 2px rgba(0,0,0,.05), 0 12px 32px rgba(0,0,0,.06)`。

2. **字体**（`FONT-001`，在项目根目录）：
   ```bash
   node <skill>/scripts/fetch-font.mjs --family "Noto Sans SC" --weights 500 --text-file fonts/chars.txt
   node <skill>/scripts/fetch-font.mjs --family "Inter" --weights 500,700
   node <skill>/scripts/fetch-font.mjs --family "Instrument Serif" --weights 400
   ```
   字体栈写 `"Noto Sans SC", sans-serif`、`"Inter", sans-serif`、`"Instrument Serif", serif`。实测渲染后 `.hf-font-cache/` 不存在。

3. **弹簧做成 GSAP 缓动**：`DET-004` 的弹簧闭式解按补间进度取值，补间时长取到弹簧基本停稳：
   ```js
   function springEase(D, zeta, w) { return p => (p >= 1 ? 1 : spring(p * D, zeta, w)); }  // spring 见 DET-004
   gsap.set("#w1", { opacity: 0, y: 40, scale: 0.96 });                                  // 初始状态在时间线外（DET-006）
   tl.to("#w1", { opacity: 1, duration: 0.15, ease: "none" }, t0 - 1 / 30)                // 提前 1 帧，第一可见帧落在 t0（AUD-002）
     .to("#w1", { y: 0, scale: 1, duration: 0.9, ease: springEase(0.9, 0.5, 14) }, t0);
   ```

4. **镜头**（`CRAFT-012`）：镜头是 t 的闭式函数，由代理时钟在每帧调用；关键帧写焦点与缩放，缩放按对数插值；手持浮动在停顿段前后 0.2 秒内降到 0；落地抖动从撞击时刻起算：
   ```js
   const CAM = [{ t: 0, x: 960, y: 540, s: 1 }, { t: 2.4, x: 960, y: 540, s: 1 },
                { t: 3.3, x: 1060, y: 540, s: 1.35 }, { t: 4.3, x: 1060, y: 540, s: 1.35 }, { t: 4.9, x: 960, y: 540, s: 1 }];
   const STILL = [[5.0, 6.25], [8.0, 10.0]];          // 停顿段：镜头完全不动
   const SHAKES = [{ t: 7.5, a: 8, k: 10, f: 9 }];     // 幅度 px、衰减率、频率 Hz
   const ph = rng(11), P1 = ph() * 6.28, P2 = ph() * 6.28, P3 = ph() * 6.28;   // rng 见 DET-001
   function clamp(x, a = 0, b = 1) { return x < a ? a : x > b ? b : x; }
   function sineIO(p) { return -(Math.cos(Math.PI * p) - 1) / 2; }
   function camAt(t) {
     let i = 0; while (i < CAM.length - 1 && t >= CAM[i + 1].t) i++;
     const a = CAM[i], b = CAM[Math.min(i + 1, CAM.length - 1)];
     const p = b.t > a.t ? sineIO(clamp((t - a.t) / (b.t - a.t))) : 0;
     return { x: a.x + (b.x - a.x) * p, y: a.y + (b.y - a.y) * p, s: Math.exp(Math.log(a.s) + (Math.log(b.s) - Math.log(a.s)) * p) };
   }
   function handMask(t) {
     return STILL.reduce((m, [a, b]) => Math.min(m, t < a - 0.2 || t > b + 0.2 ? 1 : t >= a && t <= b ? 0 : t < a ? (a - t) / 0.2 : (t - b) / 0.2), 1);
   }
   function renderCam(t) {
     const c = camAt(t), m = handMask(t);
     let dx = 4 * m * (Math.sin(2 * Math.PI * 0.13 * t + P1) + Math.sin(2 * Math.PI * 0.31 * t + P2)) / 2;
     let dy = 4 * m * (Math.sin(2 * Math.PI * 0.17 * t + P2) + Math.sin(2 * Math.PI * 0.27 * t + P3)) / 2;
     for (const k of SHAKES) if (t >= k.t) { const u = t - k.t, e = k.a * Math.exp(-k.k * u); dx += e * Math.sin(2 * Math.PI * k.f * u); dy += 0.6 * e * Math.sin(2 * Math.PI * k.f * u + 1.3); }
     document.getElementById("cam").style.transform = `translate(${960 - c.x * c.s + dx}px, ${540 - c.y * c.s + dy}px) scale(${c.s})`;
   }
   ```
   落版字标在 `#cam` 外时，把同一组 `dx`、`dy` 加到字标容器的 `translate` 上，抖动才作用到它。实测：停顿段 5.0–6.25 秒与落版 8.17–10 秒，用宽 300px 的区域按原分辨率测（`analyze.py motion --roi … --thresh 0.02`）没有运动区间。

5. **逐帧内容用代理时钟**：打字、镜头这类每帧重算的内容挂在一个代理补间的 `onUpdate` 上（`fui-hud` 技术配方第 4 步同一写法）：
   ```js
   const clock = { t: 0 };
   tl.to(clock, { t: DUR, duration: DUR, ease: "none", onUpdate: () => { renderCam(clock.t); renderType(clock.t); } }, 0);
   renderCam(0); renderType(0);
   function renderType(t) { document.getElementById("typed").textContent = TEXT.slice(0, clamp(Math.floor((t - 2.6) * 12), 0, TEXT.length)); }
   ```

6. **容器变形**：位置用 `x`、`y`，尺寸用 `width`、`height`，圆角用 `borderRadius`，同一个补间里完成。禁止补间 `top`、`left`：0.8.96 的 lint 报 `gsap_non_transform_motion`（error），`check` 不通过。
   ```js
   tl.to("#box", { width: 900, height: 260, x: -50, y: -60, borderRadius: 20, duration: 0.5, ease: "expo.inOut" }, 4.5);
   ```

7. **光标点击**：按下与抬起写成一个往返补间。两个首尾相接的补间（前一个在 4.27 结束、后一个从 4.27 开始）会报 `overlapping_gsap_tweens` warning。
   ```js
   tl.to("#cursor", { scale: 0.84, duration: 0.07, ease: "power2.out", yoyo: true, repeat: 1 }, 4.2);
   ```

8. **快切**：每个词用 `tl.set` 切换显隐，时刻写成 `帧号 ÷ fps`（`CRAFT-005`），音效写同一个帧号：
   ```js
   const F = n => n / FPS;   // 6.25 秒 → floor(6.25 × 30) = 187
   tl.set("#c1", { opacity: 1 }, F(187)).set("#c1", { opacity: 0 }, F(195))
     .set("#c2", { opacity: 1 }, F(195)).set("#c2", { opacity: 0 }, F(202))
     .set("#c3", { opacity: 1 }, F(202)).set("#c3", { opacity: 0 }, F(210));
   ```
   实测直接写 6.25 时切换落在第 188 帧，比按 `floor` 放在第 187 帧的音效晚 1 帧；按上面写法，`analyze.py rhythm` 测得瞬变在 6.233、6.5、6.733 秒，`sync` 三处偏差 −0.1、0、0.6 帧。

9. **字标落下**：字标每个字母包一个 `inline-block` 的 `<span>`，`transform-origin: 50% 100%`；第 i 个字母 `t0 = T + i × 0.055`：`opacity` 1（0.05 秒）→ `y` 0（0.28 秒 `power2.in`）→ `scaleX` 1.12、`scaleY` 0.82（0.06 秒）→ 回到 1（`springEase(0.3, 0.45, 30)`）。有品牌母版时按 `CRAFT-008` 拆母版路径，动画写法相同。

10. **图解**：连线 `<path pathLength="1">` 初始 `stroke-dasharray: 1 2`、`stroke-dashoffset: 1`，补间 `attr: { "stroke-dashoffset": 0 }` 画出；部件以 `back.out(1.7)` 从 0.9 倍弹入。压暗写成两条补间：部件与连线 `opacity: 0.4`，被压暗部件的标签 `color: "#6E6E69"`。放大进入用第 4 步的镜头推到 2.2 倍。实测推近时 `check` 报 `escaped_container` 与 `panel_out_of_canvas` 两条版面 warning（推近后部件出画是预期），按 `HF-006` 在交付说明里写明原因。

11. **声音**（`AUD-005`、`AUD-006`）：清单按「声音」一节写。实测 10 秒探针 17 个事件（拍数 20）、`space` 开启、音床 1.25：两次合成逐字节一致，`input_plr` 10.01、linear，打勾 `pop` 比音床高 3.34 dB。HyperFrames 渲染出的成片 −14.1 LUFS、真峰值 −0.49 dBTP（字标落地的 impact 起音处），按 `AUD-004` 第 1 步把归一音轨直接合回后 −14.0 LUFS、−3.78 dBTP，`check.sh` 0 个 ❌。

## 翻车点

- 加装饰性的粒子、彩纸、闪点（`CRAFT-014`）
- 把整页缩成小卡片逐张展示（`CRAFT-016`）
- 单词只用透明度淡入，没有位移与弹簧
- 通篇一种缓动，所有动作都是同一个软 S 形
- 停顿段里还在慢推，或手持浮动没有降到 0
- 相邻两拍的收尾方式相同；分界处没有元素跨过去，一页一页翻
- 强调色作文字低于 4.5:1，例如把只上图形的 `#17A05E`（3.14:1）用在文字上；压暗部件的标签用透明度压暗
- 音乐从第一帧铺满，盖住动作声
- 底色加渐变或暗角，一支片里出现两个以上强调色
- 叙事照搬「模板故事」顺序
